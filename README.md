# 🏡 Agro-Smart 2026 - Sustainable Agritourism & Smart Guest Experience Framework

> **nZEB Eco-Resort Architecture (14 Rooms, 6 Wooden Cabins, IoT Energy Management & Automated Check-in)**

## 📌 Overview
**Agro-Smart 2026** is a modular open-source framework for building and operating energy-independent agritourism resorts. Featuring nZEB energy standards (solar array + heat pumps), digital self-check-in, and automated HVAC power scaling via **Gemini AI Core**, this model cuts operational energy overhead under 8%.

---

## 🏗️ Repository Architecture
* `contracts/` - Smart contracts for automated guest bookings and utility rewards (`AgroSmartGuestToken.sol`).
* `ai-core/` - Python engine (`gemini_resort_energy_manager.py`) managing energy load balancing and digital guest experience.
* `financials/` - Financial breakdown for the €1,443,000 turnkey resort implementation.
